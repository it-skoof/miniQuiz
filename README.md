# Проект QUIZ
Игра в слова по карточкам. Если пользователь приложения знает слово, то он продолжает игру до тех пор пока слова не кончились или пока у него имеется интерес.

## Функционал приложения
![alt text](image.png)<br/>
<b>Кнопка "Далее"</b><br/>
При нажатии на кнопку происходит подгрузка новых слов. Как только переключение доходит до допустимого предела (3 слова), то происходит подгрузка новых слов также в количестве 3-х<br/><br/>
![alt text](image-1.png)<br/>
<b>Кнопка "Показать ответ"</b><br/>
Показывает перевод на игровой карточке<br/><br/>
<i>Также имеется непосредственно такая же кнопка и на самой карточке</i><br/>
![alt text](image-3.png)<br/>
<br/>
![alt text](image-2.png)<br/>
<b>Кнопка "Перемешать"</b><br/>
Производит перемешивание слов (колоды). Теперь ты точно не угадаешь какое слово следующее)<br/><br/>

![alt text](image-4.png)<br/>
<b>Кнопка "Добавить в избранное"</b><br/>
Если пользователю не дается слово или наоборот он не хочет забыть его, то он может добавить его в избранное<br/><br/>

![alt text](image-5.png)<br/>
<b>Кнопка "Список избранных слов"</b><br/>
Отображает список ваших избранных слов. В этом списке пока можно только просматривать и удалять слова.
Если пользователь не выбрал ни одного слова, то этого меню не будет на странице<br/>

## Стек приложения
- <b>State manager</b> - Zustand
- <b>Client</b> - React + Typescript
- <b>Bundler</b> - Vite
- <b>Test</b> - Vitest
- <b>Style</b> - styled-components + react-icons
